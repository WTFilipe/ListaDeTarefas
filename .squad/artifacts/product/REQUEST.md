# Solicitação

Crie um app de lista de tarefas. Cada tarefa pode ter um titulo e a descricao da tarefa. Cada tarefa pode ter uma label customizada pelo usuario (com cor). Deve ter uma busca, a busca deve considerar tanto titulo quanto descricao da tarefa. A lista pode ser ordenada por ordem alfabetica e por data de criacao. Alem disso, cada tarefa pode ter uma data limite. Deve ter um indicador em cada tarefa indicando a proximidade da data limite.
