# Respostas — Descoberta do produto

- **q1** (single_choice) — Como os dados das tarefas devem ser armazenados?
  - Somente no aparelho, funcionando offline (padrão sugerido)
- **q2** (multiple_choice) — Quais dispositivos precisam de suporte?
  - Celular Android (padrão sugerido)
- **q3** (single_choice) — Uma tarefa pode ser marcada como concluída? Se sim, o que acontece com ela na lista?
  - Sim: checkbox move a tarefa para uma seção/aba 'Concluídas'
- **q4** (single_choice) — Como as labels devem funcionar?
  - Uma label por tarefa, cor escolhida em uma paleta fixa (padrão sugerido)
- **q5** (single_choice) — O app terá uma única lista ou várias listas/projetos?
  - Uma única lista de tarefas (padrão sugerido)
- **q6** (single_choice) — Quais estados o indicador de proximidade da data limite deve mostrar?
  - 'Atrasada', 'Hoje', 'Amanhã' e 'Próximos 7 dias' (padrão sugerido)
- **q7** (single_choice) — O app deve enviar lembretes/notificações da data limite?
  - Sem lembretes no MVP; apenas o indicador visual na tarefa (padrão sugerido)
- **q8** (multiple_choice) — Quais opções de ordenação a lista deve oferecer?
  - Ordem alfabética do título (A-Z), Ordem alfabética do título (Z-A), Data de criação (mais recente primeiro), Data de criação (mais antiga primeiro), Data limite (mais próxima primeiro), Data limite (mais distante primeiro)
